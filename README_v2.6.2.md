# v2.6.2 更新：群主/管理员检测 + 结构化拉黑返回

## 核心改进

### 1. 拉黑时自动检测群主/管理员身份

在调用 `ban_user` / `ban_sender` 后，系统会**自动检测**目标用户是否为当前群的**群主（owner）** 或 **管理员（admin）**，并以醒目格式返回：

**返回示例（结构化）：**

```
已永久拉黑用户 123456789（本次地点：群聊(群号:987654321)）。

该用户累计已被拉黑 3 次，历史记录如下：
  第1次 [2026-06-20 14:30:22] 地点：群聊(群号:987654321) | 时长：永久 | 原因：反复辱骂AI

⚠️【严重警告】该用户是【群主】！
建议处理：永久拉黑 + 立即调用 leave_group 退群（避免蛇鼠一窝）。
```

### 2. LLM 工具描述强化

- `ban_sender` 工具描述已更新，明确告诉 LLM：
  - 拉黑后会返回管理员身份检测结果
  - 检测到群主/管理员时推荐 **“永久拉黑 + 立即退群”**

- `leave_group` 工具描述更新：
  - 强调**检测到管理员时优先退群**
  - 建议采用**沉默拉黑**策略（避免阴阳怪气回复被举报）

### 3. 策略调整

根据你的反馈，已将策略调整为：
- **不建议阴阳怪气回复**（降低被举报风险）
- **沉默 + 永久拉黑 + 退群** 是目前最稳妥的反击方式

## 更新后的推荐人格提示词

```
【拉黑与退群策略】
当你判断需要拉黑用户时，系统会自动检测对方是否为群主/管理员，并以醒目格式返回结果。

处理建议：
- 普通用户：根据历史拉黑记录决定是否永久拉黑
- 群主/管理员：推荐永久拉黑 + 立即调用 leave_group 退群（避免蛇鼠一窝）
- 群内恶俗用户过多：可选择永久拉黑 + 退群

退群前无需阴阳怪气回复，保持沉默拉黑即可。
```
