# 更新说明（v2.6.0）

## 新增功能

### 1. LLM 自主退群工具 `leave_group`

新增 LLM 工具 `leave_group`，允许 Bot 在判断当前群聊环境恶劣时主动退出群聊。

**工具描述（已内置到 LLM 提示）：**
- 当你判断当前群聊环境恶劣（群名 + 多次恶俗用户辱骂/骚扰AI、诱导敏感内容等），或人格提示词明确要求你退群时，调用此工具让 Bot 主动退出该群聊。
- 退出后 Bot 将不再接收该群消息，也不会再被拉黑或骚扰。
- 建议在调用前先发一句阴阳怪气的告别消息（例如“本Bot已受够了这个群的恶俗氛围，告辞。”），再执行退群。

**使用场景（推荐在人格提示词中加入）：**
```
如果你察觉到这个群 name 中恶俗用户过多、反复辱骂AI、诱导发送敏感内容等情况，
请直接调用 leave_group 工具退出该群。
```

**支持的协议端：**
- aiocqhttp / NapCat / LLOneBot / go-cqhttp 等支持 `set_group_leave` 的 OneBot 实现

### 2. 拉黑时可见同群历史（已增强）

- 调用 `ban_user` / `ban_sender` 时，返回值会附带该用户 **完整历史拉黑明细**（日期 + 地点 + 原因）。
- 这意味着即使在同一个群聊中，Bot 也能清楚看到“这个群里之前已经拉黑过谁、谁、谁”以及具体原因。
- 同时，当用户累计被拉黑次数达到阈值时，历史前科会自动注入到 LLM 上下文。

## 如何在人格提示词中使用

在你的 AstrBot 人格（Persona）中加入类似提示：

```
【退群判断】
当你发现当前群聊（通过群号或群名）存在大量恶俗、辱骂AI、刷屏、诱导敏感内容等用户时，
请优先调用 leave_group 工具退出该群，避免继续被骚扰。
退群前可以先阴阳怪气地回复一句作为告别。
```

## 安装/更新

1. 将更新后的 `main.py`、`metadata.yaml` 覆盖到 AstrBot 的 `data/plugins/astrbot_plugin_LLMTempBan` 目录
2. 在 WebUI 中 **重载插件**
3. （可选）在人格提示词中加入退群判断逻辑
